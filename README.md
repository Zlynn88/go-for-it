# Go For It! – Math Challenge

A responsive, portrait-first browser math game for students.

## Run locally
1. Extract this folder.
2. Open `index.html` in a modern browser.
3. Internet is only needed to load the optional Nunito Google Font; the game itself runs locally.

## Game features
- Multiplication and exact-division modes using factors 2–9
- 30, 60, 90, or 120 second rounds
- 3–2–1–GO countdown
- Touch keypad and physical keyboard number input
- Correct answers flash green, score +1, then the next question appears
- Wrong complete answers clear automatically without red styling
- Timer blinks in the final 10 seconds
- Result praise and medium pastel confetti
- PLAY AGAIN returns to Welcome

## Project files
- `index.html`: screen structure
- `style.css`: responsive pastel styling and animations
- `script.js`: game logic
- `assets/mascot/`: mascot pose images (preliminary cutouts)
- `assets/ui/`: SVG visual assets and references
- `docs/DESIGN_SPECIFICATION.md`: approved design specification

## Notes
Interactive controls are implemented in HTML/CSS/JavaScript rather than static button images.
No background music or sound effects are used.
