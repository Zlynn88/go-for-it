Go For It! Complete UI Asset Reference Pack

Includes:
- Main action button SVG references: START, PLAY AGAIN, multiply, divide, back
- Time selection SVG references: 30, 60, 90, 120 seconds
- Number keypad SVG references: digits 0–9
- Answer field states: empty, filled, correct-green
- Timer and score visual references
- Four result-message wordmarks
- Decorations: cloud, star, confetti
- Backgrounds: welcome, time selection, game, result, portrait and landscape
- Palette reference

Important implementation note:
These SVG files are visual assets/reference shapes. Interactive elements such as buttons,
timer, score, keypad, selected states, answer validation and countdown must be implemented
as responsive HTML/CSS/JavaScript components, not as static images. This keeps the game
accessible, touch-friendly and functional on phones, tablets and computers.

Mascot character PNGs are maintained in the separate mascot asset package.
Please visually inspect mascot cutout edges before production use.
